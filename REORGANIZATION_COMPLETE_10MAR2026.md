## Version Tracking

### How Date Suffixes Work

Each file includes date in filename: `FILENAME_DDMMMYYYY.md`

**Example**:
- STARTUP_SETUP_GUIDE_10MAR2026.md (current version)
- If updated tomorrow: STARTUP_SETUP_GUIDE_11MAR2026.md (new version)
- Old version can be archived to `docs/archive/`

**Benefits**:
- No branch conflicts
- Clear version history
- Easy rollback if needed
- Self-documenting currency
