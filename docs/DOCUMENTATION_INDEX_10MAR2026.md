## Document Naming Convention

All documentation follows this naming pattern:

```
DOCUMENT_NAME_DDMMMYYYY.md
```

Example:
```
STARTUP_SETUP_GUIDE_10MAR2026.md
├─ STARTUP_SETUP_GUIDE = Document name
├─ 10MAR2026 = Date (Day + Month + Year)
└─ .md = Markdown extension
```

**Benefits**:
- Easy version tracking
- Clear currency of information
- No branch conflicts
- Historical record keeping
